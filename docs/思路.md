# 思路说明（写报告时可以直接从这里取材）

> 这份文档不是报告，是**写报告用的素材**：每个设计决策的动机、支撑数字、以及踩过的坑。
> 报告里的每一段都可以在这里找到对应的原始结论。

## 1. 一句话

用纯经典图像处理在 DRIVE 眼底图上做血管二值分割，按「预处理 → 血管增强 → 分割 → 后处理」四步搭一条可消融的流水线，
用 5 折交叉验证 + 每折独立调参得到 OOF 指标，并与同数据的 U-Net 集成（0.816）对照。

## 2. 问题与约束

- **输入/输出**：512×512 彩色眼底图 → 同尺寸二值血管图；只在视场内评价。
- **数据**：DRIVE training 部分全部 20 张（带像素级 GT），另有 20 张无标注测试图（GT 不公开，只能提交平台）。
- **不平衡**：血管像素占视场的 8.6%（逐图 6.6%–11.7%），所以主指标必须是 Dice / 敏感度，不能用准确率。
- **细结构**：标注血管中位半宽约 1 px，定位差 1 px 就会显著拉低 Dice——这是传统方法的天花板所在。
- **照明不均**：视场内灰度直方图是单峰宽峰（图 2），全局阈值切开的其实是"周边暗区 vs 中心亮区"。

## 3. 流水线为什么这样搭

| 环节 | 做法 | 为什么这么选 |
|---|---|---|
| 预处理 | 绿通道 → 1%/99% 分位归一化 → CLAHE | 血红蛋白对绿光吸收最强，G 通道血管—背景对比度最高；CLAHE 只做局部均衡，避免全局均衡放大噪声 |
| 血管增强 | 多尺度 Frangi（Hessian 特征值） | 血管是"管状暗脊"，二阶导数在法向响应强；多尺度覆盖 1–8 px 的粗细变化 |
| 分割 | 局部自适应阈值（主）/ 滞后双阈值（增强分支） | 局部阈值对径向光照梯度免疫；滞后阈值保细血管连通性 |
| 后处理 | 面积过滤 → 填小孔 → 膨胀（可选）→ 视场裁剪 | 血管是细长结构，孤立小斑点是噪声；阈值化会让血管变细 1 px |

## 4. 四个关键决策（每个都有数字支撑）

### 决策 1：把评价区域修对 —— 影响最大的一步
- **问题**：绝对阈值（灰度 > 8）估视场，把视网膜外一圈 10–20 灰度的暗带也算了进去。实测视场占比在 0.68–0.86 之间波动，几何上应在 ~0.64；那条带上几乎没有真实血管，所有方法都在那里产生伪响应。
- **做法**：两步掩膜——粗掩膜（阈值 + 填洞 + 最大连通域）估出视网膜内部中位亮度，再用 `0.35 × 中位亮度` 作为相对阈值重切，最后内缩 8 px。
- **效果**：视场稳定在 0.637，GT 96% 仍在掩膜内；C0 0.019→0.257、C1 0.565→0.662、C2 0.604→0.696、C3 0.608→0.696。
- **教训（值得写进报告）**：评价区域的定义本身就能改变结论，比大多数算法改动影响更大。先钉死口径，再谈方法。

### 决策 2：Frangi 的两个改造
- **尺度自适应**：σ_max 取 `0.006 × 视场直径`（512 尺寸下约 3 px）。踩过的坑：最初用**包围盒对角线**估直径，σ_max 被高估 1.41 倍，细血管响应被粗血管淹没，Dice 卡在 0.55；改成按直径后同一套代码多出 +0.04。
- **逐尺度归一化**：每个尺度先除以该尺度的 99.5% 分位再取 max，避免大尺度响应主导；统计量只在内缩 12 px 的视场里算，避开边界。
- **效果**：C1 0.662 → C2 0.696（配对 p≈6×10⁻⁵），AUC 从 0.740 升到 0.889。

### 决策 3：滞后双阈值（高分位做种子、低分位做生长）
- 单阈值会把细血管切碎；滞后阈值让"与强响应连通"的弱响应保留下来。
- 参数（q_low, q_high）由交叉验证在每折训练集上选，大多数折落在 (0.85, 0.97)。

### 决策 4：后处理 —— 一次"看起来该有用、实际几乎没用"的验证
- C3 在 C2 上加面积过滤 + 填孔 + 可选膨胀，只多 +0.0002（p=0.196）。交叉验证多数折选了 `dilate=0`。
- **原因**：Frangi + 滞后阈值的输出已经接近标注厚度，膨胀补偿没有用武之地；而同一套后处理接在**局部阈值**分支上曾带来约 +0.04——它补偿的是"偏细"这种系统性偏差，不是普适增益。
- **写法建议**：这段是可以体现"分析能力"的地方，写成"验证一个合理假设并证伪"，比硬凑提升更可信。

### 失败的尝试（也值得写）
把视场外像素用边界中值填平、再 CLAHE，期望抹掉"视网膜—黑"阶跃。开/关消融：C1 −0.003、C2 −0.006、C3 −0.006，一致地略微变差。函数保留在 `enhance.border_fill()`，默认关闭。

## 5. 实验协议（写"数据描述"时用）

- 20 张图按编号 `mod 5` 分 5 折，每折 4 张测试。
- 每个方案在**其余 16 张**上网格搜索超参，取平均 Dice 最高者，再在留出的 4 张上评测 → 每张图的超参不来自它自己，汇总得到 OOF 指标。
- 指标全部在视场内计算：Dice、Se、Sp、Acc、AUC（AUC 用响应图排序算，衡量排序质量，不受单一阈值影响）。
- **为什么 20 张还站得住**：评价是像素级的（每张 26 万像素）；配对设计消掉图像难度（同一批图、同一折、只换方法）；实测配对差值的标准差中位数约 0.03，20 张图能稳定分辨约 0.018 的 Dice 差异——报告只对 ≥0.02 的差异下结论。

## 6. 最终数字

| 方案 | Dice | Se | Sp | Acc | AUC | 单图耗时 |
|---|---|---|---|---|---|---|
| C0 灰度 + 全局 Otsu | 0.257 | 0.634 | 0.506 | 0.521 | 0.604 | 0.011 s |
| C1 绿通道 + CLAHE + 局部自适应阈值 | 0.662 | 0.666 | 0.949 | 0.912 | 0.740 | 0.014 s |
| C2 + 多尺度 Frangi + 滞后阈值 | 0.696 | 0.666 | 0.965 | 0.925 | 0.889 | 0.065 s |
| **C3 + 后处理** | **0.696** | 0.667 | 0.964 | 0.925 | 0.889 | 0.018 s |
| 参考：ResNet34+U-Net 集成（同 20 图 OOF） | 0.807 | 0.870 | 0.952 | 0.938 | 0.974 | GPU 2 h |

配对检验（`results/stats.md`）：C1→C2 +0.034（p≈6×10⁻⁵）显著；C2→C3 +0.0002（p=0.20）分辨不出。

> DL 对照取运行时 `retina/runs` 下所有可用 OOF（按图平均），训练 run 增加后该数字会变；本文引用的是同一时刻的快照。

> 注意：C0 的 Dice 0.257 看着低，但它的 Se 有 0.63、Sp 只有 0.51——即"把一半背景也判成血管"。全局阈值的问题不是完全失效，而是**无法同时兼顾两类错误**，这个对比很适合作图。

## 7. 能说什么 / 不能说什么

**能说**
- 在纯经典方法、CPU 秒级、无训练的前提下做到 Dice 0.696，是同数据 U-Net 集成（0.807）的 86%。
- 最大的单项收益来自评价区域修正（+0.09～0.24）与 Hessian 增强（+0.034），后处理几乎无效。
- 差距集中在细小血管连通性：DL 的 Se 0.856 vs 本文 0.667。

**不能说**
- 不能说"传统方法接近深度学习"——差 0.11，且在细血管上肉眼可见。
- 不能拿 Kaggle 测试集分数（0.756）和本文 OOF 并列，口径不同。
- 不能把 <0.02 的差异说成"更好/更差"（20 张图分辨不出）。

## 9. 踩过的坑（都可写进"代码修改描述"）

1. **Otsu 的平台**：两峰之间类间方差完全相等，`argmax` 取到平台左端 → 阈值落在暗峰上、目标被全排除。取平台中点才对。
2. **σ 用对角线估直径**：高估 1.41 倍，细血管响应被淹没（−0.04）。
3. **缓存键不全**：只记参数名不记实际 σ/掩膜，改了实现仍命中旧缓存，结果与代码对不上。
4. **FOV 绝对阈值**：把视网膜外暗带圈进评价区（见决策 1）。
5. **直方图混入过渡带**：视场内统计若不内缩，会多出一个 0 灰度尖峰，与"单峰"的判断自相矛盾。
6. **边界填充**：直觉上正确，实测略有害（−0.006）。

## 10. 复现

```bash
pip install -r requirements.txt
export VESSEL_DATA=/path/to/segmentation      # 或 --data-dir
python -m src.run_all --data-dir "$VESSEL_DATA" --out results
python -m src.demo   --data-dir "$VESSEL_DATA" --image 5      # 单图演示
python -m tests.test_core                                     # 自检
```

产物：`results/summary.csv`（主表）、`metrics_per_image.csv`（逐图）、`stats.md`（配对检验）、`figures/`。
